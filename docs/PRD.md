# PRD.md

## Problem
Users face daily decision fatigue over "what to listen to right now." Existing recommendation systems focus on discovering new or popular tracks rather than helping users pick from their own existing library based on mood, weather, and situation.

## Target User
Students and young adults who use Spotify regularly and want a quick, low-effort way to decide what to listen to before heading out.

## Core Value
Personalized, in-the-moment music decisions from your own library — no new discovery needed, just the right pick for right now.

## Core Features
-Spotify account connection (import existing playlists/tracks)
-Automatic weather detection based on location
-Mood & situation input (quick-reply buttons + free text)
-AI-based recommendation from the user's own library, combining mood, weather, and situation
-One-tap redirect to Spotify for playback

## Non-goals
-Not a new-music discovery engine
-No payment or subscription features
-No social sharing or multi-user features
-No in-app playback (always redirects to Spotify)
-No offline mode

## Success Criteria
-Perceived quality: across repeated real-world use, the recommended track/playlist feels appropriate to the situation at least 4 out of 5 times (subjective self-assessment)
-Functional completeness: the full core flow (Spotify connect → mood/context input → weather reflected → AI recommendation → redirect to Spotify) runs end-to-end without errors in a live demo
