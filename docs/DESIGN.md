# DESIGN.md

## Design Goal
A modern, iOS-style web app that feels clean, native, and effortless for students.

## Visual Tone
-Modern
-Minimal
-Polished
-Native-feeling (iOS-inspired)
-Card-based when useful

## Main Screens
-Landing Page (Spotify login/connect)
-Mood & Context Input Page (mood, situation, weather display)
-Recommendation Result Page

## UI Rules
-Use clear button text.
-Use labels for inputs.
-Use semantic headings.
-Avoid icon-only actions.
-Avoid random design changes.
